# Voxel

Herramientas básicas para el análisis de imágenes médicas volumétricas (3D), escritas en pytorch. Voxel ofrece métodos para trabajar con datos de rejillas de imágenes y mallas triangulares, teniendo en cuenta su representación en un sistema de coordenadas del mundo (o del escáner). La caja de herramientas es completamente compatible con GPU y se ha desarrollado dando especial énfasis a su uso en aplicaciones de aprendizaje profundo. ¡Pronto habrá más documentación!

Se puede instalar Voxel con:

```
pip install voxel
```

Si encuentra útil este paquete en su trabajo, por favor cite la siguiente publicación (para la cual se desarrolló originalmente este paquete).
> [VoxelPrompt: Un agente de visión para el análisis de imágenes médicas de extremo a extremo](https://arxiv.org/abs/2410.08397)<br>
> Andrew Hoopes, Neel Dey, Victor Ion Butoi, John V. Guttag, Adrian V. Dalca
